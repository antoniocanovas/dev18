# 📚 Ejemplos de Uso - Búsqueda Inteligente de Productos

Este directorio contiene ejemplos prácticos de cómo usar el módulo de Búsqueda Inteligente.

## 📋 Índice de Ejemplos

### 🔍 Búsquedas Básicas
- `basic_search_examples.py` - Ejemplos de búsquedas simples
- `advanced_search_examples.py` - Búsquedas complejas y filtros

### 🤖 Sistema Conversacional  
- `conversation_flow_examples.py` - Flujos conversacionales típicos
- `custom_questions_examples.py` - Personalizar preguntas del sistema

### 🧠 Aprendizaje Automático
- `learning_patterns_examples.py` - Crear y usar patrones de aprendizaje
- `analytics_examples.py` - Extraer métricas y analytics

### 🔗 Integraciones
- `api_usage_examples.py` - Usar via API desde aplicaciones externas
- `webhook_examples.py` - Implementar webhooks personalizados

### 📊 Casos de Uso Reales
- `ecommerce_integration.py` - Integración con tienda online
- `sales_assistant.py` - Asistente de ventas con IA
- `inventory_optimizer.py` - Optimización de inventario

## 🚀 Cómo Usar los Ejemplos

### 1. Ejecutar en Shell de Odoo
```bash
# Acceder al shell de Odoo
./odoo-bin shell -c odoo.conf -d tu_database

# Ejecutar ejemplo
exec(open('./examples/basic_search_examples.py').read())
```

### 2. Copiar y Pegar Código
Los ejemplos están diseñados para ser copiados directamente en:
- Terminal de Odoo (Configuración → Técnico → Terminal)
- Scripts personalizados
- Desarrollo de funcionalidades adicionales

### 3. Adaptar a Tu Caso de Uso
- Modificar los parámetros según tus necesidades
- Personalizar la lógica de negocio
- Integrar con otros módulos de Odoo
