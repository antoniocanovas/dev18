Sale Purchase Link MTO

Módulo para vincular órdenes de venta con órdenes de compra en modo Make to Order

📋 Descripción

Este módulo permite vincular automáticamente las órdenes de venta con las órdenes de compra correspondientes cuando se utiliza la estrategia MTO (Make to Order), facilitando el seguimiento y control de la cadena de suministro.

⚙️ Instalación

1. Copiar el módulo

cp -r sale_purchase_link_mto /path/to/odoo/addons/

2. Actualizar lista de aplicaciones

# En Odoo: Aplicaciones → Actualizar lista de aplicaciones

3. Instalar

# Buscar "Sale Purchase Link MTO" e instalar

🚀 Uso

Configuración básica:

1. Producto MTO:
• Ir a Inventario → Productos
• Seleccionar producto → pestaña Inventario
• Ruta: "Make to Order" br> 2. Crear orden de venta:
• Ventas → Órdenes → Crear
• Añadir producto MTO
• Confirmar orden

Funcionalidades principales:

  • Vínculo automático: Al confirmar venta MTO se crea enlace con compra
  • Seguimiento: Vista de órdenes vinculadas en ambos formularios
  • Estados sincronizados: Actualización automática de estados

Ejemplo de uso:

# Crear venta → Automáticamente vincula compra sale_order = self.env['sale.order'].create({ 'partner_id': customer_id, 'order_line': [(0, 0, { 'product_id': mto_product_id, 'product_uom_qty': 5 })] }) sale_order.action_confirm() # Crea vínculo automático

📊 Campos añadidos

  • sale.order: linked_purchases_count, linked_purchase_ids
  • purchase.order: linked_sales_count, linked_sale_ids
  • Botones inteligentes: Acceso rápido entre órdenes vinculadas

🔧 Dependencias

'depends': ['sale', 'purchase', 'stock']
