Sale Product Matrix Filter

Filtrar matriz de productos por valores de atributo

Versión 18.0.1.0.1 - ¡Bug KeyError Corregido!

Descripción

Este módulo extiende la funcionalidad de la matriz de productos en las ventas de Odoo 18 Enterprise, permitiendo filtrar los productos mostrados en la matriz basándose en valores específicos de atributos.

🐛 Corrección Importante - v18.0.1.0.1

CORREGIDO: Error KeyError: 'attribute_value_id'

El código ahora usa correctamente el campo 'product_attribute_value_id' en lugar del incorrecto 'attribute_value_id'.

Si experimentabas errores al usar el filtro, esta versión los resuelve completamente.

Funcionalidades

✅ Campo de Filtro

Nuevo campo value_filter_id en órdenes de venta para seleccionar un valor de atributo específico.

✅ Filtrado Inteligente

Solo muestra variantes que contengan el atributo seleccionado, manteniendo estructura y funcionalidad de la matriz original.

✅ Experiencia de Usuario

Campo visible y fácil de usar con actualización automática de la matriz al cambiar el filtro.

Casos de Uso

Ejemplo 1: Filtrado por Talla

Producto: Camiseta
Atributos: Color (Rojo, Azul, Verde) x Talla (S, M, L, XL)
Filtro seleccionado: "Talla: L"
Resultado: Solo muestra Rojo-L, Azul-L, Verde-L

Ejemplo 2: Filtrado por Color

Producto: Zapatos
Atributos: Color (Negro, Marrón) x Talla (38, 39, 40, 41, 42)
Filtro seleccionado: "Color: Negro"
Resultado: Solo muestra Negro-38, Negro-39, Negro-40, etc.

Instalación y Actualización

Nueva Instalación:

  1. Copiar el módulo a tu directorio de addons de Odoo
  2. Actualizar lista de aplicaciones
  3. Instalar "Sale Product Matrix Filter"

Actualización desde v18.0.1.0.0:

  1. Sustituir los archivos del módulo
  2. Reiniciar Odoo
  3. Ir a Apps > Sale Product Matrix Filter > Upgrade

Solución de Problemas

❌ Error KeyError: 'attribute_value_id'

✅ RESUELTO en v18.0.1.0.1 - Actualiza a la versión más reciente

❓ El campo no aparece en el formulario

  • Verifica que el módulo esté instalado correctamente
  • Asegúrate de que el módulo 'sale_product_matrix' esté instalado
  • Reinicia Odoo y actualiza el módulo
  • Verifica que estés en la pestaña "Other Info" del formulario de venta

❓ El filtro no funciona

  • Asegúrate de estar usando productos con atributos configurados
  • Verifica que el producto tenga modo de agregación "matrix"
  • Reinicia Odoo después de actualizar el módulo

Uso

  1. Abrir orden de venta
  2. Ir a pestaña "Other Info"
  3. En sección "Sales", seleccionar valor en "Filtro de Variante"
  4. Agregar producto con matriz - solo aparecerán variantes filtradas
