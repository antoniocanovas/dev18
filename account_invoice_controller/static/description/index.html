Account Invoice Controller

Módulo para Odoo 18 Enterprise que permite crear facturas de cliente mediante webhook JSON con autenticación por tokens de usuario.

Características principales

  • API REST segura con tokens por usuario
  • Creación automática de partners
  • Soporte para campos personalizados
  • Líneas estructuradas (productos, secciones, notas)
  • Control de acceso granular
  • Auditoría completa

Configuración

URL del webhook:
/api/a7k9m3x2w8v5n1q6z4r0

Método: POST
Autenticación: Header X-API-TOKEN

Uso del módulo

  1. Instalar el módulo Account Invoice Controller
  2. Crear tokens de acceso en "Webhook Facturas > Tokens de API"
  3. Configurar sistemas externos para enviar JSON al webhook
  4. Monitorear accesos y gestionar tokens
